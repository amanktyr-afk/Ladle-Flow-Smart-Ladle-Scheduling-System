# Ladle-Flow-Smart-Ladle-Scheduling-System
The primary purpose of Ladle ( A large, open-topped cylindrical container that carries Molten Steel) Flow is to simulate and monitor ladle operations in a Steel Melting Shop (SMS), track ladle availability, and manage heat(Molten Steel) scheduling through a real-time dashboard to improve operational visibility and ladle utilization.
